# Try KAIROS on Preprod

1. **Prepare your wallet.** Use Midnight Lace in its browser profile, select **Preprod**, and have DUST available. Start the two local proof services described in [USAGE.md](USAGE.md): Kairos on 6301 and Lace on 6300.
2. **Open KAIROS.** Visit [the demo](https://kairos-dapp.vercel.app) and select **Enter the Garage**. If artwork is slow, the optional **Enter while artwork loads** action appears after eight seconds in the updated app.
3. **Connect.** Open **Wallet**, choose Lace and approve the connection. In **Settings**, enter a strong local storage password, select **Save password**, and check the local proof server. This password is separate from your wallet recovery phrase.
4. **Use the product.** Open **Trading Engine**, check the round and close time, choose a side in an open round, prepare and download the private opening, then acknowledge that you saved it. If the eight slots are full, wait for the operator to complete or expire the round and start the next one. See [USAGE.md](USAGE.md) for the resolver and public trading flows.
5. **Confirm.** Submit once, approve the wallet request, and wait for a finalized receipt. Keep its transaction ID. A submitted ID alone is not finalization. Retain the opening privately even if an error occurs, and check wallet history before retrying.
6. **Give feedback.** Send the project owner your public Preprod wallet address, optional public finalized transaction ID, date and feedback through the same collection channel that invited you, or contact [the product X profile](https://x.com/usekairosdApp). Do not send a seed, key, local password, or private opening as feedback. Only share an opening with the trusted resolver through a private channel.

Names and emails are unnecessary for the public tester roster. The original collection-form URL is not present in the supplied CSV or repository; the owner can add the verified URL to outreach materials.
