# Bug Task Template

```text
Failure: <exact observed behavior/error>
Expected: <expected behavior>
Reproduction: <command/steps/input>
Environment: <network/runtime/version when relevant>

Reproduce before editing. Trace the responsible boundary, test one hypothesis at a time, add a regression test, make the smallest root-cause fix, then rerun the original reproduction and required gates. Do not claim success from a signing prompt, partial transaction stage, or unrelated passing test.
```
