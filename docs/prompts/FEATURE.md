# Feature Task Template

Use this as a starting user prompt; keep actual task details specific.

```text
Goal: <observable outcome>
Constraints: <scope, compatibility, UX, security/privacy constraints>
Acceptance: <tests or behaviors that prove completion>
Non-goals: <what must not change>

Inspect the repository and applicable AGENTS.md before editing. Research only material unknowns. Use subagents only for independent work. Implement the smallest coherent solution, verify it with the required repository gates, review the diff, and create coherent green commits. Report exact evidence and any unverified area.
```
